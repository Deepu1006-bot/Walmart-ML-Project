# Git Workflow - Walmart ML Project

1. Check changes with `git status`.
2. Create a feature branch before major changes.
3. Keep raw data and secrets out of commits when required by `.gitignore`.
4. Run the data validation and test suite before committing.
5. Use descriptive commit messages.
6. Review the diff before pushing.
7. Never commit credentials, tokens, or private configuration.
8. Keep experiment parameters, metrics, and model artifacts reproducible.
